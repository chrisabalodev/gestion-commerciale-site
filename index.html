Deux façons de travailler

Un logiciel de bureau et une application web

Mêmes écrans, mêmes documents, mêmes règles. Choisissez selon votre organisation.

Logiciel de bureau

Pour Windows. Idéal pour un magasin, une boutique ou un dépôt.

  • S'installe comme n'importe quel programme et fonctionne sans internet.
  • Un seul poste, ou plusieurs caisses reliées à un poste serveur par le réseau local.
  • Données sur vos machines, sauvegardées automatiquement chaque jour.
  • Mises à jour apportées sur clé USB : les autres postes sont prévenus.
Télécharger Windows 10 ou 11 · 64 bits

Application web

Dans le navigateur. Idéal pour plusieurs points de vente ou le suivi à distance.

  • Hébergée sur un serveur : on s'y connecte depuis un ordinateur ou une tablette, et depuis un téléphone avec la 1.4.
  • Plusieurs agences partagent les mêmes clients, articles et chiffres en temps réel.
  • Le gérant suit le tableau de bord sans être au magasin.
  • Rien à installer sur les postes : la mise à jour se fait sur le serveur.

Plusieurs postes, une seule base

En réseau local, sans internet

Un ordinateur sert de serveur ; les caisses et les bureaux s'y connectent par le câble ou le Wi-Fi du magasin. Tout le monde voit les mêmes clients, le même stock et les mêmes numéros.

  1. Le poste serveur garde les donnéesIl enregistre tout et fait la sauvegarde automatique.
  2. Les postes clients s'y connectentOn indique l'adresse du serveur une seule fois, à l'installation.
  3. Les mises à jour se propagentImportée sur le serveur, la nouvelle version est proposée aux autres postes.
Questions fréquentes

Avant d'installer

Faut-il une licence ?

Le logiciel fonctionne gratuitement pendant 30 jours. Pour continuer, l'écran de licence affiche un identifiant : envoyez-le à AB-DIGICOM et vous recevrez votre clé.

Mes données sont-elles conservées lors d'une mise à jour ?

Oui. Installez la nouvelle version par-dessus l'ancienne : les données restent dans votre dossier utilisateur et la sauvegarde automatique continue.

Windows affiche « Windows a protégé votre ordinateur ». Que faire ?

C'est le message habituel pour un programme récent. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Vous pouvez vérifier le fichier avec son empreinte SHA-256, indiquée sous le bouton de téléchargement.

Stable ou Preview : laquelle choisir ?

La stable pour travailler au quotidien. La Preview contient les nouveautés en cours de test : essayez-la d'abord sur un poste sans données importantes, ou faites une sauvegarde avant.
